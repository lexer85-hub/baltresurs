# Балтресурс

Статическая копия сайта baltresurs.ru. Страницы, стили, скрипты и изображения находятся в `dist/`.

## Локальный запуск

Выполните из корня репозитория:

```sh
python3 -m http.server 8077 --bind 127.0.0.1 --directory dist
```

Откройте [главную страницу](http://127.0.0.1:8077/). Формы работают в режиме предпросмотра. Для отображения интерактивных карт нужен доступ к Яндекс Картам.
